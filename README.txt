MATTHEW ISON — POLICY RESEARCH & APPLIED ECONOMICS PORTFOLIO

GITHUB PAGES SETUP
1. Create a GitHub repository for the portfolio (or open the repository you want to use).
2. Extract this ZIP file on your computer.
3. Upload the contents of the extracted folder to the root of the repository. Keep the images and projects folders intact.
4. In GitHub, open Settings > Pages. Select Deploy from a branch, choose the main branch and / (root), then save.
5. Your site will be published at the GitHub Pages address shown in Settings > Pages.
