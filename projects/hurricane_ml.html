PROJECT OVERVIEW

Hurricane Ian Damage Classification

A machine learning classification project focused on identifying hurricane damage from imagery. The analysis classifies features in the natural environment and town buildings into damaged and non-damaged categories.

Use the portfolio links to open the hurricane map image and view the GIS graduate project PDF. Place the PDF in this folder using the filename GIS Graduate Project - MatthewIson.pptx.pdf. Replace images/hurricane.png with your actual map image to make the Open Map link show your map.
